# ⚡ Программа расчёта линии электропередачи 0,4 кВ

## Описание

Данное приложение предназначено для расчёта параметров линий электропередачи 0,4 кВ.

Функциональность включает:

- выбор сечений проводников
- проверку допустимых потерь напряжения
- оценку загрузки силового трансформатора
- расчёт токов короткого замыкания

Все вычисления выполняются автоматически при изменении параметров.

---

## Основные возможности

- Добавление и редактирование участков линии
- Автоматическое наследование параметров
- Поддержка различных типов нагрузок
- Визуализация схемы линии
- Генерация отчёта
- Сохранение и загрузка расчётов (JSON)
- Undo / Redo действий
- Поддержка светлой и тёмной темы

---

## ⚙️ Руководство по работе

| Параметр       | Описание                                      |
| -------------- | --------------------------------------------- |
| Название линии | Используется как имя файла и заголовок отчёта |
| Дата           | Устанавливается автоматически, можно изменить |
| cos φ          | Коэффициент мощности (по умолчанию 0.9)       |
| dU% доп        | Допустимая потеря напряжения                  |
| Мощность тр-ра | Используется для расчёта загрузки и токов КЗ  |
| Схема обм.     | Влияет на расчёт токов короткого замыкания    |
| Кодн           | Коэффициенты одновременности                  |
| Кнагрев        | Коэффициент для нагревательных нагрузок       |

## ⚡ Токи короткого замыкания

**Трёхфазное:**

```
Ikz3 = Uл / (1.73 * (√(Rл² + Xл²) + Zт))
```

**Двухфазное:**

```
Ikz2 = Ikz3 × 0.866
```

**Однофазное:**

```
Ikz1 = Uф / (√((2Rл)² + Xл²) + Zт0 / 3)
```

Где:

- Uл = 400 В
- Uф = 230 В
- Xл ≈ 0.3 × L
